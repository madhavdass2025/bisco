2. Electronic PIN (ePIN) Generation

An ePIN is a secure 16-character code used to activate subscription packages instantly. ePINs can be generated by members using earned commissions or by administrators in batch.

CUSTOMER SIDE
Earning Wallet to ePIN

Members can convert their earned commissions into ePINs to register downline members or gift packages.

1
Open Member Dashboard
Log in and scroll to the Generate ePIN section.
2
Choose Package
Select desired voucher tier (e.g., Voucher 300 or Voucher 600).
3
Generate PIN
Click Generate ePIN Now. Cost is deducted from your wallet balance.
4
Receive Code
A unique 16-digit code appears on screen and is sent via SMS.
ADMIN SIDE
Batch ePIN Generator

Admins can generate free ePIN batches for promotional offline sales or corporate distribution.

1
Access Schemes Portal
Navigate to admin/schemes.php via the admin menu.
2
Select Quantity & Package
Choose package type and enter quantity (e.g. 10 or 50 PINs).
3
Click Generate Batch
Click Generate ePIN Batch. No wallet balance is required.
4
Distribute PINs
View generated PIN list and copy or print them for distribution.
Note: All generated ePINs remain valid until redeemed. Once used, they are marked as redeemed and linked to the activated member account.

3. Account & Subscription Activation Methods

Members can activate their accounts and packages using three simple methods based on their payment preference:

A. Online Gateway
Automated Instant
  1. Go to Buy Package on Dashboard.
  2. Select desired subscription package.
  3. Choose **Razorpay Payment Gateway**.
  4. Pay via UPI (GPay/PhonePe), Credit Card, or NetBanking. Activation is instant.
B. ePIN Redemption
Voucher Based
  1. Obtain a 16-character ePIN code.
  2. Go to Redeem ePIN section.
  3. Paste code into input box.
  4. Click Proceed & Activate. Package activates immediately.
C. Admin Manual Activation
Bank / Offline
  1. Member pays company offline or via direct bank transfer.
  2. Admin opens admin/schemes.php.
  3. Enter member's registered mobile number & select package.
  4. Click Activate Subscription Now.
Affiliate Distribution Trigger: Regardless of activation method, as soon as a package is activated, 12-level affiliate commissions are calculated and credited instantly up the sponsor hierarchy.
